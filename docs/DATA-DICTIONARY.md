# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 name, link, cannot, audit。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `author`、`peer`、`authority`、`similarity`、`permitted` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

权威编号 0 表示未确认。先按相同权威编号归并，再按相似度降序、端点升序处理候选边。禁止关系检查跨整个分组，不能经第三人绕过。不同非零权威编号阻止合并。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
